**Fun Time at Forrest's!**
---
A game hand coded by me for my friend Forrest's birthday! (Happy birthday Forrest!)

**Overview**
---
This game combines intriguing gameplay mechanics with a customizable user experience. Players can tweak game settings such as volume, night settings, and monster difficulty to create a gameplay environment tailored to their preferences.

**Features**
---
_Dynamic Gameplay_: Engage with monsters, navigate through the night, and immerse yourself in the game's unique challenges.
_Customizable Settings_: Tailor the game's difficulty and ambiance using the Settings menu. Adjust volume, select night options, and customize monster difficulty to your liking.
_Sound Engineering_: Integrated sound engine to enhance gameplay immersion.
_Debug Mode_: Developers and avid gamers can activate a debug mode for troubleshooting or a more in-depth understanding of the game mechanics.
_This game does not have save functionality, so please feel free to use this feature to resume your progress between sessions._
**Getting Started**
---
_Prerequisites_
Ensure you have Java installed.

_Installation_
---
For a compiled .exe version of this game please contact me! 
All files are present for install if you want to try manually.
(You will want to run Runner.java to boot up the game)

_Starting the Game_   
---
Navigate to the settings screen using the Settings button if you wish!
Customize the settings to your preference using the interface.
Press the start button and enjoy!
